# Constants used in `ut_type`

|name|constant|meaning|
|----|--------|-------|
|`EMPTY`|0|empty|
|`RUN_LVL`|1|indicates system run level has changed|
|`BOOT_TIME`|2|system boot time|
|`NEW_TIME`|3|time info after system clock changes|
|`OLD_TIME`|4|time info before system clock changes|
|`INIT_PROCESS`|5|shows it's proccess by `init`|
|`LOGIN_PROCESS`|6|session reader process user login|
|`USER_PROCESS`|7|normal process|
|`DEAD_PROCESS`|8|closed process|
|`ACCOUNTING`|9|unused item|
