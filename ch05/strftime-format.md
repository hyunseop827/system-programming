# Formats

| Specifier | Meaning (English) | Specifier | Meaning (English) |
|---|---|---|---|
| `%a` | Abbreviated weekday name (locale) | `%A` | Full weekday name (locale) |
| `%b` | Abbreviated month name (locale) | `%B` | Full month name (locale) |
| `%c` | Locale’s appropriate date and time representation | `%C` | Century as a 2-digit number (`year/100`) |
| `%d` | Day of month (01–31) | `%D` | Date as `%m/%d/%y` |
| `%e` | Day of month (1–31), space-padded (e.g., `" 7"`) | `%F` | Date as `%Y-%m-%d` (ISO 8601) |
| `%g` | ISO 8601 week-based year (00–99) | `%G` | ISO 8601 week-based year (0000–9999) |
| `%h` | Abbreviated month name (same as `%b`) | `%j` | Day of year (001–365/366) |
| `%H` | Hour (00–23) | `%I` | Hour (01–12) |
| `%k` | Hour (0–23), space-padded | `%l` | Hour (1–12), space-padded |
| `%m` | Month (01–12) | `%M` | Minute (00–59) |
| `%p` | AM/PM (locale) | `%P` | am/pm (lowercase) |
| `%r` | Locale’s 12-hour clock time (includes `%p`) | `%R` | Time as `%H:%M` |
| `%s` | Seconds since Unix epoch (1970-01-01 00:00:00 UTC) | `%S` | Second (00–60) |
| `%t` | Tab character | `%T` | Time as `%H:%M:%S` |
| `%n` | Newline character | `%U` | Week number (00–53), Sunday as first day; week 01 starts with first Sunday |
| `%u` | ISO weekday number (1–7, Monday=1) | `%V` | ISO 8601 week number (01–53) |
| `%w` | Weekday number (0–6, Sunday=0) | `%W` | Week number (00–53), Monday as first day; week 01 starts with first Monday |
| `%x` | Locale’s appropriate date representation | `%X` | Locale’s appropriate time representation |
| `%y` | Year without century (00–99) | `%Y` | Year with century (e.g., 2026) |
| `%z` | UTC offset (e.g., `+0900`) | `%Z` | Time zone abbreviation/name (e.g., `KST`) |
